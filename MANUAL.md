# MANUAL

An Inventory Management Program designed on the cli for ease of use and low memory consumption. Currently on Development Phase and expected to be ready by Mid November 2026.

Branch 'stable-tui' is also available for a more intuitive build without the need of a manual.

--help  ,   -h  >   basic option under GNU cli standard to show available commands for the tool
--add [NAME,SKU,PRICE,QUANTITY]  ,   -a  >   Add a new item to the inventory database
--list  ,   -l  >   lists all items inside the database (soon to have a filter option)
--edit  ,   -e  >   edit an item. Can select whether to change name, SKU, price, or quantity
--delete,   -d  >   delete an item from the database
--find,     -f  >   search an item by its SKU
